# Violin Outline - src\shoulder_rest\parts\violin_outline.py

Then we want a class representing the left and right curves. 
Also the class should have part extruded from a face created from these two curves with horizontal lines attaching the top and bottom.
This is extruded 38mm to create a simplified "Violin Block" to aid in visualizing the violin loation.
